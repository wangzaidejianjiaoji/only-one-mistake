# A 的需求与验收

目标是让已经验证的经验参与当前及后续决策，在适用条件不变时避免已知无效路径。代码位于 `D:\only-one-mistake`，远程主分支为 `main`；本仓库不维护全流程个人工作流体系。

## 需要通过的行为

1. 工具失败、用户纠正、长难问题和成功验证都参与问题台账，不只监听用户输入。
2. 验证成功后可立即检索本会话经验；项目经验有明确范围、环境、来源、失败方法、正确方法、验证与失效条件。
3. 已知的精确失败路径在可干预节点被检查；环境、工具或 shell 不同不误阻断；有意复现采用明确的一次性例外。
4. 压缩与恢复保留未解决问题和有效经验；旧总结不关闭后来消息，用户中断终止复盘。
5. 来源增量学习只处理新增、变更和失效结论；相同来源不重复提交，旧版本可追溯，不以模板数量衡量收益。
6. 用户安装、更新、检查、卸载保留其他 hooks 与状态；拒绝覆盖用户编辑，不自动授予信任。
7. 插件和源码仅发行 A，打包后本地文档链接有效，测试和实际证据区分清楚。

## 验收层次

自动测试验证接口和状态行为；真实 SSH 试点验证只读连接和经验复用；显式适配器验证请求与结果协议。真实桌面对话自动触发和新故障自动修复需要宿主日志与业务证据，当前不能由前三者替代。
